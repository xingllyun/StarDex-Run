文档归属：星云云络科技

## 一、项目概述

StarDex-Run 是面向 iOS 侧载环境独立自研的 Android APK 运行时，采用纯解释执行方案，无需越狱、无需 JIT 编译。项目完整覆盖 APK 导入校验、签名处理、DEX 字节码解释、安卓 API 原生映射、原生 SO 库兼容、应用沙盒管理全链路，优先适配侧载签名环境，主打稳定、可控、可自研扩展。

### 支持系统版本

iOS 16、iOS 17、iOS 18、iOS 19、iOS 26、iOS 27

主力调试设备：iPhone 14 Pro Max iOS 26.4.2

部署硬性要求：侧载签名证书必须开启 **大地址空间**、**大内存** 两项权限，普通开发者证书无法完整运行

### 核心运行规则

1. 所有加固 APK 直接拦截，不接收、不脱壳、不兼容
2. 未签名 / 签名失效 APK 禁止直接运行，自动跳转内置签名工具页
3. 纯字节码解释执行，不实现 JIT / AOT 编译
4. 安卓 API 按需映射 iOS 原生能力，不完整复刻安卓全量框架
5. 优先侧载场景深度适配，越狱仅做基础兼容，不开发越狱专属特权

## 二、整体架构

自顶向下共七层，每层职责单一，可独立迭代：

| 层级 | 模块名 | 核心职责 |
| --- | --- | --- |
| 1 | UI 交互层 | 全页面交互、应用管理、工具入口、日志展示 |
| 2 | APK 工具层 | 包解析、加固检测、签名校验、内置重签名工具 |
| 3 | 应用框架层 | 安卓 API 接口映射、组件生命周期、系统服务模拟 |
| 4 | DEX 解释核心层 | DEX 文件解析、字节码解释执行、方法调度、线程管理 |
| 5 | 原生库加载层 | ELF 解析、SO 加载、符号解析、系统调用映射 |
| 6 | 沙盒管理层 | 应用数据隔离、目录模拟、权限管控 |
| 7 | iOS 系统适配层 | 证书权限检测、系统版本适配、原生 API 桥接 |

## 三、模块详细设计

### 3.1 UI 交互层

全页面自研实现，不照搬同类项目界面风格。

**主界面**

- 顶部导航栏：项目名称、全局运行状态、设置入口
- 应用列表区：卡片式展示已导入应用，包含应用图标、包名、版本号
- 卡片操作：启动、删除、查看详情、导出运行日志
- 底部快捷栏：导入 APK、签名工具、设置、关于

**APK 签名工具页（独立一级页面）**

- 文件导入：支持从系统文件选择原始未签名 APK
- 信息预览区：解析展示包名、版本、权限列表、加固检测结果
- 签名操作区：本地执行签名处理，全程无需联网
- 输出管理：签名完成的 APK 保存至应用沙盒目录，提供「一键导入运行」快捷按钮
- 免责提示：明确标注「不支持脱壳、不支持破解加固包，仅处理合法原始安装包」

**设置页**

- 运行配置：执行线程数调整、单应用内存上限、日志等级切换
- 权限状态：实时展示当前证书的「大地址空间」「大内存」权限开启状态，权限缺失红色高亮弹窗告警
- 通用管理：缓存清理、沙盒目录管理、重置应用列表
- 赞赏入口：页面底部放置赞赏码，标注「自愿支持开发，不解锁任何功能」

**运行日志页**

- 实时滚动输出，按等级区分颜色：Info（白）、Warn（黄）、Error（红）
- 筛选能力：按包名、日志等级、关键词过滤
- 导出功能：一键导出完整日志为本地文本文件，用于问题排查

**关于页**

- 项目版本号、开源协议
- 版权声明：星云云络科技
- 支持系统列表、已知限制说明

### 3.2 APK 工具层

**加固检测模块**

- 检测覆盖：360 加固、腾讯乐固、爱加密、梆梆加固、百度加固等主流加固方案
- 检测特征：DEX 壳标记、SO 壳特征、加固专属资源文件、特殊类名前缀
- 处理逻辑：检测到加固特征直接弹窗拦截，拒绝导入，提示文案：不支持加固后的 APK，请获取原始未加固安装包

**签名校验模块**

- 校验范围：V1 签名完整性、V2 签名完整性、签名有效期、签名证书合法性
- 处理逻辑：
  1. 签名有效 → 允许导入应用列表
  2. 无签名 / 签名无效 → 弹窗提示，提供「前往签名」按钮，一键跳转内置签名工具页

**APK 解析模块**

- 解压 APK 包体，解析 AndroidManifest.xml
- 提取应用图标、包名、版本名、版本号、权限列表
- 分离 DEX 文件、SO 库文件、资源文件，按对应路径存入应用沙盒

### 3.3 DEX 解释核心层

**格式支持**

- DEX 版本：035、038、039
- 位数支持：32 位 DEX、64 位 DEX 自动识别适配
- 多 DEX 支持：自动处理主 DEX 与分包 DEX，统一类加载

**核心实现**

- 字节码解释器：完整覆盖 Dalvik 核心指令集，逐条解释执行
- 寄存器模拟：完整模拟 v0~v15 通用寄存器、方法调用栈帧
- 类加载机制：类查找 → 验证 → 准备 → 解析 → 初始化全流程
- 方法调度：静态方法、实例方法、构造方法、native 方法统一分发
- 异常处理：异常抛出、捕获、栈回溯完整实现
- 多线程管理：模拟安卓线程模型，映射 iOS 原生线程调度

**执行保护**

- 指令执行计数阈值，防止死循环卡死宿主应用
- 单应用内存上限管控，超出阈值主动终止并抛出异常
- 非法指令、非法地址访问主动捕获，输出详细错误日志

### 3.4 应用框架层（安卓 API → iOS 原生映射）

所有安卓 API 均调用 iOS 原生能力实现等价功能，不嵌套额外虚拟机。

- 应用组件类：Activity、Service、BroadcastReceiver、Intent
- 视图系统类：TextView、Button、ImageView、EditText、ListView 等
- 系统服务类：包管理、窗口管理、电量/网络/传感器、通知
- 数据存储类：SharedPreferences、SQLite、文件存储
- 网络通信类：HttpURLConnection、Socket、网络状态监听
- 多媒体基础类：Bitmap、MediaPlayer、相机

### 3.5 原生库加载层（SO 兼容）

已实现基础能力：ELF 文件解析（32/64 位节表、符号表、重定位表）、SO 加载、基础符号解析、最小系统调用映射。

预留扩展位：完整 ELF 转译层扩展接口、系统调用全量映射扩展位。当前阶段仅保证简单无依赖 SO 可加载运行，复杂依赖 SO 暂不兼容。

### 3.6 沙盒管理层

- 每个应用独立沙盒目录，数据完全隔离
- 目录结构模拟安卓标准路径：/data/data/[包名]/ 下的 files、cache、databases 等子目录
- 权限管控：应用仅能访问自身沙盒内文件
- 缓存管理：单应用缓存清理、全局缓存清理

### 3.7 iOS 系统适配层

**证书权限检测**

- 启动自动检测「大地址空间」「大内存」两项签名权限
- 权限缺失弹窗明确提示
- 权限不足时自动降级运行配置

**系统版本适配**

- 区分 iOS 16-19 与 iOS 26-27 两套系统分支逻辑
- 侧载签名权限逻辑按系统版本分支处理

**原生桥接**

- 统一桥接接口，调用 iOS 原生 Objective-C / C 接口
- 自动管理 ObjC 对象与 Java 对象生命周期映射
- 安卓线程与 iOS 线程调度一一映射
